Relational Database Schema Architecture

Entity definitions, Primary Keys, Foreign Keys, and Table Constraints

schema: public
Books
10 records
  • book_id INT (PK)
  • title VARCHAR(100)
  • author VARCHAR(100)
  • genre VARCHAR(50)
  • quantity INT >= 0
  • available_copies INT <= quantity
Constraints: quantity >= 0, available_copies <= quantity.
Members
10 records
  • member_id INT (PK)
  • name VARCHAR(100)
  • email VARCHAR (UNIQUE)
  • phone VARCHAR(15)
  • department VARCHAR(50)
Constraints: UNIQUE email constraint prevents duplicate member registrations.
Borrowings
15 records
  • borrow_id INT (PK)
  • book_id FK → Books
  • member_id FK → Members
  • borrow_date DATE DEFAULT TODAY
  • due_date DATE >= borrow
  • return_date DATE (Nullable)
Constraints: due_date >= borrow_date, return_date IS NULL OR >= borrow_date.
